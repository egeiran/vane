Review-guide for runden BRANCH: N issues, hvert som én commit. Hver seksjon har hva som er endret, hva du bør sjekke, og før og etter. Trykk «Før» og «Etter» på bildene for å bytte.

Slik går runden
Hvert issue får en egen branch fra BRANCH. Det testes, reviewes av en egen agent og squash-merges til én commit når sjekkene er grønne. Til slutt går BRANCH til main i én PR, som du merger selv med merge commit. Ingenting bygges, sendes som OTA eller legges i App Store Connect.
